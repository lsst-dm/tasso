Welcome to tasso!

τάσσω is an Ancient Greek word that means to arrange, to put in order. It is an etymological root of "taxonomy."

tasso is a cutout display and labeling app built by Eric Bellm using FastAPI and Safir. Some components were derived from cm-service.

The tasso source code is available on Github.

See the Guide to learn more about how to use tasso.
